# Docs (GitHub Pages)

Astro Starlight site with the [Ion](https://louisescher.github.io/starlight-ion-theme/) theme.

## Local

```bash
cd docs
npm ci
npm run dev
```

## Build

```bash
cd docs
npm run build
npm run preview
```

The site uses `base: '/woovi-go-sdk'` for GitHub Pages at
`https://orce-me.github.io/woovi-go-sdk/`.

Enable **Settings → Pages → Source: GitHub Actions** after the first push.
